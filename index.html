🔬 Pre2Pub Retraction Tracker v2.2

Track preprints citing retracted references → check if corrections made in journal publications

Two usage modes:
① Basic — Preprint-to-publication linking: Upload any CSV with preprint DOIs (column named DOI, optionally Title). The tool will find corresponding journal publications using Methods A–F. No other files needed.
② Full — Retraction tracking: Upload preprints from the Feet of Clay detector (which cites retracted references) along with Retraction Watch data. The tool will link preprints to publications AND check whether retracted references were corrected.

📖 Legend & Terminology

A
bioRxiv API — Ground truth link from preprint server
B
Crossref Relations — Ground truth from publisher metadata
C
PubMed/Pre2Pub — Title search + author matching per Langnickel 2022 (4 criteria)
D
Cabanac — Crossref search (Cabanac 2021). Hi: Jaccard≥0.80. Lo: 0.25–0.80 + ORCID/name match
E
Title-only — Fallback, needs manual verification
F
Europe PMC — Curated preprint-publication links from Europe PMC
FoC
FoC-only flag — DOI flagged by Feet of Clay but not in Retraction Watch (may be EoC, tortured phrases, etc.)
Still
Still Cited — Journal article still cites retracted ref(s)
Fixed
Corrected — Retracted refs removed from journal article
Pre-prep
Before Preprint — Ref retracted before preprint posted
~Prep
Around Preprint — Same month as preprint (month-level precision only)
Between
Between — Ref retracted between preprint and publication
Ambig
Ambiguous — Year-only precision, same year — cannot determine timing
~mo
Same Month — Additional marker indicating month-level precision

🔌 Data Sources

Metadata (authors, dates, titles) — Retrieved from Crossref API for both preprints and journal articles. Author names are normalized (lowercase, non-letters removed) and matched using last name + initials overlap.
Reference lists — Primary: Crossref API (publisher-deposited). Fallback: OpenAlex API when Crossref has no refs (OpenAlex extracts refs from PDFs). The refs_source column indicates which was used.
Retraction data — From your uploaded Retraction Watch CSV. Dates used for timeline classification.
Preprint-publication links — Methods A/B are ground truth (bioRxiv API, Crossref relations). Methods C-F use algorithmic matching with varying confidence levels.
